HALLOWEEN NAVIGÁTOR 0.5 – FRISSÍTÉS

GitHub: kattints a meglévő index.html fájlra, majd a ceruza (Edit) ikonra. Töröld a teljes régi tartalmat, illeszd be az új index.html tartalmát, majd Commit changes. Vagy töröld a régit, utána töltsd fel az újat.

Két fájlt cserélj: index.html és sw.js (gyorsítótár verziófrissítés). A manifest.webmanifest, icon.svg, koordináták maradhatnak.

Javítás: Valhalla POST, units km, polyline6 dekódolás, csoportos kérés és részletes HTTP-hiba. Az algoritmus továbbra sem garantál globálisan optimális útvonalat.
